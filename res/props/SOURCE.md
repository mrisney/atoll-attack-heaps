# Prop sprites

Copied from Marc Risney's WildCurrent project
(`github.com/mrisney/WildCurrent`, `assets/art/bank/`). These are painted,
top-down sprites. In this game they're mapped onto shallow domes
(`render/SpriteProps.hx`), so they read as 3D canopies, bushes and boulders
from the RTS camera.

The `-shadow` variants aren't used, because the game casts real shadows from
the sprite's alpha.
